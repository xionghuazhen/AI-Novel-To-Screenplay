## 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| 前端框架 | Next.js 14 | SSR + App Router，React 生态成熟 |
| 样式 | Tailwind CSS | 快速响应式布局，暗色主题 |
| 后端框架 | FastAPI | 异步支持，自动 OpenAPI 文档 |
| Agent 编排 | LangGraph | 有向无环图工作流，状态管理 |
| LLM 封装 | 统一 Provider | 通过环境变量一键切换模型 |
| 数据验证 | Pydantic v2 | 类型安全，自动序列化 |
| 输出格式 | YAML | 可读性强，支持注释，影视行业友好 |

## Agent 设计原则

1. **单一职责**: 每个 Agent 只负责一个转换阶段
2. **流水线协作**: 上游 Agent 的输出作为下游 Agent 的输入
3. **容错设计**: 单个 Agent 失败不影响整体流程
4. **信息累积**: Character ID 贯穿全流程，保证引用一致性

## 长文本处理策略

- 章节级分片: 每章独立处理，避免 token 超限
- 内容摘要: 剧情分析使用章节摘要而非全文
- 分段场景: 单章超过 8000 字时分段提取场景
- RAG 预留: config 中保留 rag_memory_enabled 开关
